# Baby Yoda Bot — TonConnect Manifest

Public hosting for the TonConnect manifest used by [@babyyodatonbot](https://t.me/babyyodatonbot).

- `manifest.json` — TonConnect dApp manifest (name, icon, URLs)
- `icon.png` — dApp icon shown in wallet UI

Manifest URL: `https://hollowtradr.github.io/yoda-tonconnect/manifest.json` (once Pages enabled)
Or via raw: `https://raw.githubusercontent.com/hollowtradr/yoda-tonconnect/main/manifest.json`
